# ধাপ ৪ ও ৫: প্রোডাকশন লঞ্চ গাইড ও প্রথম ১০০ পেইড কাস্টমার আনার রোডম্যাপ (Sellora AI)

এই গাইডে ধাপে ধাপে দেওয়া হলো কীভাবে আপনি **`৳০` প্রাথমিক খরচে** `Sellora AI`-কে ইন্টারনেটে লাইভ করবেন, আসল AI ও ডাটাবেস যুক্ত করবেন এবং প্রথম ১০০ জন পেইড সাবস্ক্রাইবার (`৳৫০,০০০ – ৳১,০০,০০০/মাস MRR`) আনবেন।

---

## অংশ ক: ৩০ মিনিটে ইন্টারনেটে লাইভ করার ৫টি ধাপ

### ধাপ ১: আসল AI API Key নেওয়া (৫ মিনিট)
1. [OpenRouter.ai](https://openrouter.ai) সাইটে গিয়ে Google দিয়ে লগইন করুন।
2. **Keys -> Create Key** বাটনে ক্লিক করে একটি API Key (`sk-or-v1-...`) কপি করুন।
   - *বোনাস টিপস:* OpenRouter-এ অনেক ফ্রি মডেল (`google/gemini-2.0-flash-exp:free`) দিয়ে `৳০` খরচেও শুরু করতে পারবেন, আর মাত্র `$5` (~৳৬০০) রিচার্জ করলে `openai/gpt-4o-mini` দিয়ে **প্রায় ১,২০০+ ক্যাম্পেইন** তৈরি হবে!
3. `Sellora AI` ড্যাশবোর্ডের **ফাউন্ডার অ্যাডমিন ও লঞ্চ** ট্যাবে গিয়ে অথবা `.env.local` ফাইলে কী-টি বসিয়ে দিন।

### ধাপ ২: ফ্রি ক্লাউড ডাটাবেস সেটআপ — Supabase (৫ মিনিট)
1. [Supabase.com](https://supabase.com)-এ ফ্রি একাউন্ট খুলে **New Project** (`sellora-ai`) তৈরি করুন।
2. বাম মেনু থেকে **SQL Editor -> New Query**-তে যান এবং প্রজেক্টের `sellora-ai/supabase/schema.sql` ফাইলের পুরো কোড পেস্ট করে **Run** চাপুন।
3. **Project Settings -> API** থেকে `Project URL` এবং `service_role / anon key` কপি করে `.env.local`-এ বসান।

### ধাপ ৩: bKash / Nagad পেমেন্ট গ্রহণ (২টি উপায়)
- **উপায় ১ (প্রথম দিন থেকেই `৳০` খরচে চালু — ইতিমধ্যেই অ্যাপে যুক্ত!):**
  - কাস্টমার আপনার পার্সোনাল বা মার্চেন্ট **bKash / Nagad / Rocket** নম্বরে Send Money করে `Sender Number` ও `TrxID` দেবে।
  - আপনি **ফাউন্ডার অ্যাডমিন ড্যাশবোর্ড** থেকে ১ ক্লিকে ভেরিফাই/অ্যাপ্রুভ করতে পারবেন!
- **উপায় ২ (১০০% অটোমেটিক — কাস্টমার বাড়লে):**
  - [UddoktaPay.com](https://uddoktapay.com) থেকে API Key নিয়ে ফাউন্ডার প্যানেলে বসালেই আপনার অ্যান্ড্রয়েড ফোনের SMS পড়ে সিস্টেম একা একাই পেমেন্ট কনফার্ম করে ক্রেডিট যোগ করে দেবে (ট্রেড লাইসেন্স ছাড়াই চলে!)।

### ধাপ ৪: GitHub ও Vercel-এ ফ্রি লাইভ হোস্টিং (১০ মিনিট)
1. আপনার কম্পিউটার বা প্রজেক্ট ফোল্ডারটিকে **GitHub**-এর একটি প্রাইভেট রিপোজিটরিতে পুশ করুন।
2. [Vercel.com](https://vercel.com)-এ গিয়ে **Add New Project** চেপে GitHub রিপোজিটরি সিলেক্ট করুন।
3. **Environment Variables** অংশে আপনার `OPENROUTER_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` পেস্ট করে **Deploy** চাপুন।
4. মাত্র ৬০ সেকেন্ডে আপনার অ্যাপ `https://sellora-ai.vercel.app` লিংকে সারা বিশ্বের জন্য লাইভ হয়ে যাবে! চাইলে পরে `৳১,২০০/বছর` দিয়ে `.com` ডোমেইন যুক্ত করে নিতে পারবেন।

প্রতিদিন মাত্র ১টি ৩০ সেকেন্ডের স্ক্রিন-রেকর্ড ভিডিও বানান:
- **প্রথম ৩ সেকেন্ড (Hook):** *"গ্রাফিক ডিজাইনারকে মাসে ১০ হাজার টাকা দিচ্ছেন? দেখুন আমি মাত্র ২০ সেকেন্ডে জামদানি থ্রি-পিসের বুস্ট পোস্টার আর অ্যাড কপি কীভাবে বানাই!"*

- **শেষ ৭ সেকেন্ড (CTA):** *"কমেন্টে **AI** লিখুন—আমি ৫টি ফ্রি পোস্টার বানানোর লিংক ইনবক্সে পাঠিয়ে দিচ্ছি!"*

### কৌশল ২: Facebook F-Commerce গ্রুপে ফ্রি ভ্যালু পোস্ট
বাংলাদেশের **F-Commerce Entrepreneurs / Women Entrepreneurs (WE) / Uddokta** গ্রুপগুলোতে একটি পোস্ট দিন:
> *"আজ প্রথম ২০ জন অনলাইন পেজ ওনারকে আমি আপনাদের পণ্যের ছবি দিয়ে একদম ফ্রিতে ১০৮০×১০৮০ প্রিমিয়াম অফার ব্যানার ও বুস্ট কপি বানিয়ে দেবো—কমেন্টে আপনার পণ্যের ছবি ও দাম দিন!"*

### কৌশল ৩: Meta Conversion Ads (যখন ১০-১৫ জন অর্গানিক পেইড ইউজার চলে আসবে)

- **ফানেল হিসাব:** দিনে ১০০ জন পেজ অ্যাডমিন ফ্রি ৫ ক্রেডিট টেস্ট করলে মাত্র ৩–৪ জন পেইড প্ল্যান (`৳৪৯৯` / `৳৯৯৯`) নিলেই আপনার অ্যাড খরচের **৪–৫ গুণ টাকা প্রথম মাসেই উঠে আসবে**!
